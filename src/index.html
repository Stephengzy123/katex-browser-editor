Features & help

Writing and formatting

Equation: type LaTeX directly, for example \frac{a}{b}, without dollar signs.

Text + math: mix plain text with $inline math$ or $$display math$$. Also supports \(…\) and \[…\].

Insert notation builds formulas from editable fields. Format formats selected text or inserts a block at the cursor. Alignment, centered equations, matrices and cases are available.

Use \begin{align} a &= b \\ c &= d \end{align} for numbered alignment, or align* without numbers. The & marks alignment and \\ separates rows. Separate-line insertion uses $$…$$ in Text + math mode and \\ in Equation mode.

Basic Markdown

In Text + math mode, use **bold**, *italic* or _italic_, ~~strikethrough~~, and backticks for inline code. Start a line with #, ## or ### for a heading, - for a bullet, or 1. for a numbered list. Triple backticks make a code block.

Math inside its delimiters keeps its LaTeX syntax. HTML, links and external Markdown images stay literal text; use Insert image for local images. PDF exports show the formatted result; source downloads preserve what you typed.

Tabs and editing

Keep up to 10 named tabs, each with its own source, images, mode and undo/redo history. Use the pencil on a tab to rename it. That name is used for downloads and suggested as the PDF filename.

Undo/redo: Cmd-Z / Cmd-Shift-Z on Mac; Ctrl-Z / Ctrl-Shift-Z or Ctrl-Y elsewhere. New edits replace the redo branch. History saves across reloads in this browser, subject to available browser storage. There is no edit-count cap.

Expand either panel for more room. The preview scrolls internally. It follows the source box height as it grows or shrinks, with the default preview height as its minimum and a page-height limit. Long text-only LaTeX wraps; PDF export fits wide equations to the page.

Images

Insert image switches Equation tabs to Text + math after confirmation. In Text + math mode, insert images, with the cursor outside a formula. Choose a width before inserting (50% by default), then resize or remove it in the preview. Those changes can be undone.

Local PNG/JPEG only: at most 10 MB, 25 megapixels and 16,000 pixels per side before processing. Images are re-encoded, with metadata removed, and reduced to at most 2,400 pixels per side. Stored images are limited to 5 MB each, 25 MB total and 32 images per tab, including images retained for undo. No SVG, GIF or remote image links.

Downloads and backups

Download .tex: source text with image markers omitted. Download PDF: opens the browser print dialog; choose Save as PDF. Only the rendered document is printed, including images, on a white page.

Export session: the current tab, including images and history. Export all tabs: all named tabs and their history. Import session: opens a single-session file in a new tab when space is available; an all-tabs backup restores its saved set of tabs.

Drafts, images and history save automatically in this browser. Keep exported JSON backups if you want a portable copy. The editor works offline and sends no documents or images to a server.
